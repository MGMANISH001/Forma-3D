Why FORMA3D

A hand-built storefront that shows what plain HTML, CSS and JavaScript can do — no frameworks, no build step.

Real-time 3D in the browser

Every product is modeled procedurally with Three.js and rendered with PBR materials and soft shadows. Rotate, zoom and re-color instantly — nothing to download or install.

Server-verified pricing

The browser never decides a price. A Django REST endpoint recomputes every quote and order from the database, so the number you see is always the number you pay.

Made-to-order flow

Each choice is captured per part — shell, cushion, finish — plus optional laser engraving. Your exact configuration travels with the item all the way to checkout.

Zero-framework frontend

Readable vanilla JavaScript, hand-written CSS design tokens and clean URLs served by Django itself. Open the folder, read the code — it is the documentation.

Dark mode & accessibility

A warm espresso-night theme with no flash on load, keyboard-visible focus states, ARIA labels on interactive parts and reduced-motion support throughout.

Mobile-first by design

Touch orbit controls, a sticky purchase bar, skeleton loading states and layouts tuned at 390px and 1440px. The configurator feels native on a phone.

Questions, answered

Everything worth knowing about the store — and about how the project itself works. Still curious? Read the full story →

Is this a real shop?

No — FORMA3D is a portfolio project built for learning and demonstration. No payments are processed and nothing is shipped. Every part of the shopping experience, however, is genuinely functional: catalog, 3D configuration, quoting, ordering and an admin panel.

How does the 3D work without an app?

Each product is generated in code with Three.js — geometry, materials and lighting — and rendered live through WebGL, which every modern browser supports. There are no model files to download and no plugin to install.

Who calculates the final price?

The server does. The browser shows a live estimate, but the Django REST API independently recomputes every quote and every order from the database. If a price and the client ever disagreed, the server wins — the safe way to build commerce.

What does laser engraving add?

Up to 24 characters of text, applied before assembly, for a flat $9.90 per item. It is configured in the panel, priced into your quote, and stored with the order — a good example of how per-item options flow through the whole stack.

Does it work well on a phone?

That was a design goal from day one. The stage responds to one-finger rotation and pinch zoom, the options panel becomes a full-width drawer, and a sticky bar keeps price and add-to-cart always reachable on small screens.

What is the project built with?

Django 6 and Django REST Framework on the backend, SQLite for storage, and a dependency-free frontend of plain HTML, CSS and JavaScript with Three.js for the 3D stage. The whole stack runs from a single Django process — see the about page for the tour.
